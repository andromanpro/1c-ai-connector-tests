# Проверки ИИконы 1.7.3

На одном срезе исходников и CFE прошли 827 выбранных тестов: 825 серверных и 2 управляемого клиента. Каждый тест сверяется по полному имени и ожидаемому контексту. Клиент завершился самостоятельно, без запроса закрытия. Локальная HTTP-фикстура проверила 13 обращений в семи сценариях.

В [манифесте](VERIFICATION.json) указаны результат, хеши и границы. [Исходный JUnit](junit-827.xml), [неизменяемые входы](inputs.json), [сборка](build.json) и [соответствие будущим Git blobs](source-to-git.json) позволяют сверить версии. CFE этого выпуска берутся из обратной выгрузки установленного и проверенного стенда; повторной сборки для публикации нет.

[Sonar всего продукта](sonar-analysis.json): 85 BSL-модулей, Quality Gate OK, 0 BUG, 0 VULNERABILITY, 48 прежних CODE_SMELL, новых замечаний нет; все 28 hotspots проверены. Профиль из 160 правил сохранён, исключения и статусы замечаний ради результата не менялись. Прежний долг типов EDT остаётся.

Проверка данных после финального прогона подтвердила точное совпадение 18 таблиц с 512 записями, настроек, пользователей и владельцев секретов. Содержимое данных и секретов сюда не включается. [След стандартов](v8std-evidence.md) проверен строгим гейтом с существующими настройками проекта.

Скрипты pipeline.py и xml_compare.py сохранены в том виде, в котором входили в зафиксированный снимок. Пути и стенд в них относятся к среде автора. Для своей среды задайте свои пути и приватное описание базы, затем получите новый снимок и результат. Учётные данные не публикуются. COM, обновление и тесты одной базы запускаются последовательно. Пользователи создаются и удаляются штатным механизмом БСП.

Новые сценарии запускаются tools/run_expert_tools_suite.py; он поднимает локальную HTTP-фикстуру и вызывает verified_yaxunit.py для заданного нового снимка. Ожидаемые контексты указываются при его создании. Обычный режим приложения не допускается. Старые результаты не переносятся на новый исходный код или другую базу.

Проверки ролей 35/35 версии 1.7.2 являются отдельным историческим результатом. Нагрузка, все живые облачные модели и экзаменатор этим набором не объявляются проверенными.
