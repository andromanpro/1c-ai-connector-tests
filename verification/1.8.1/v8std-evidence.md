## Решения

- Публичные параметры страниц необязательны, старый вызов сохранен. Новое API оценки
  описывает типы, единицы, признак отсутствия расчета и снимок тарифов (std453/std640).
- Новые пользовательские ошибки оформлены литералами НСтр; подстановки через СтрШаблон.
  Новая ветвь мониторинга передает только заданные опции, не сбрасывая модельные пределы.
- Настройки модели читаются публичным API БСП одним набором; добавленного чтения
  реквизитов ссылки через точку, запросов по одному полю в цикле и привилегированных обходов нет.
- Арифметика тарифов выполняется BSL, умножение идет до деления, итог округляется
  до 8 знаков. std535 относится к арифметике запросов: он прочитан как найденная рекомендация,
  но формальное соответствие SQL-правилу для этого BSL-расчета не заявляется.
- Страницы сокращаются по целым объектам, курсор сохраняет первый непереданный объект;
  копия результата не изменяет кеш петли. Новых модулей с повторным использованием
  возвращаемых значений не добавлено; область std724 учтена при проверке копирования.
- Переносы выражений и читаемые имена проверены по std444 и внутренним правилам;
  простые тернарные выражения допустимы. Авторских дат и парных отметок в личном проекте нет.
- На реальной управляемой форме 1.8.1 все десять новых настроек сохраняются и повторно
  открываются; независимое чтение COM подтвердило значения. Все вкладки видны,
  числовые поля компактны (std681). Четыре предела видны при прокрутке к группе.
- Уточненная подсказка правдиво описывает дополнительный финальный запрос; ее длина
  меньше 255 символов. std506 рекомендует предельно короткие подсказки, std721 дает
  специальное описание подсказок форм. Рекомендации о показе подсказок снизу и унификации
  значков вопроса остаются вопросом дальнейшего оформления: этот проход не объявляет
  все формы полностью соответствующими всем рекомендациям v8std.
