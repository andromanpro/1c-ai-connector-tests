# Проверка ИИконы 1.8.1

Один срез связывает продукт, тесты, CFE, основной YAxUnit,17 отдельных сеансов ролевых проверок и Sonar.
Основной набор: 985/985,966 серверных и 19 управляемого клиента. Роли БСП: 130 выполнений 40 методов.
Эти выполнения не следует выдавать за 1115 разных тестов. Полные JUnit сохранены отдельно.

[Манифест](VERIFICATION.json) содержит контрольные суммы и границы. [Состав исходников](source-files.json)
сохраняет точные файлы среза. Тестовый код к стандартам оформления специально не приводился.
Старые маркеры EDT и рекомендации по показу подсказок не скрываются зелёным статусом Sonar.
