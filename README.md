# Тесты ИИконы

Тестовое расширение для [ИИконы](https://github.com/andromanpro/1c-ai-connector) —
AI-коннектора для 1С:Предприятие. **532 модульных теста** (YAxUnit): коннекторы
провайдеров, вложения и форматы function calling, агентская петля, RAG и egress-политики,
мониторинг ошибок, дашборд и антиспам, MCP-сервер (диспетчер, аудит, ограничения),
генератор диаграмм, парсеры Markdown и JSON, контроль персональных данных (правила
поиска, маскировка, восстановление, режимы и отказы, журнал).

Тесты версии 1.5.0 соответствуют расширению той же версии: тег `v1.5.0` в обоих
репозиториях.

## Состав

- `src/CommonModules/Тесты_*` — тестовые модули по подсистемам;
- регистрация — `ИсполняемыеСценарии()` в каждом модуле
  (`ЮТТесты.ДобавитьТестовыйНабор(...).ДобавитьСерверныйТест(...)`);
- ассерты — `ЮТест.ОжидаетЧто(...)`.

## Как прогнать

1. В базу с ИИконой загрузите [YAxUnit](https://github.com/bia-technologies/yaxunit)
   и это расширение (оба — как расширения конфигурации).
2. Запуск из Конфигуратора/CLI:

   ```
   1cv8 ENTERPRISE /F<база> /N<пользователь> /C"RunUnitTests=<config.json>"
   ```

   где `config.json` — стандартный конфиг YAxUnit (`reportFormat: jUnit`,
   `reportPath`, при необходимости `filter.modules`).
3. Ожидаемый результат: **532 = 530 pass / 2 skipped** — два теста зависят
   от окружения (заполненный API-пользователь MCP и живой ключ провайдера
   для мультимодального вызова) и штатно пропускаются.

Тесты не требуют внешних сервисов: сетевые вызовы либо замоканы тест-швами,
либо проверяют валидацию до сети. Тесты, сеющие данные (регистры мониторинга,
аудита), убирают за собой.
